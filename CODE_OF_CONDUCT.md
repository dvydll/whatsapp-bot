> Fecha: 2026-04-27

## 1. Nuestros Valores

WhatsAppBot se dedica a proporcionar un entorno de desarrollo respetuoso y productivo para todos los contributors y usuarios.

## 2. Comportamiento Esperado

- **Respeto**: Tratar a todos con respeto y cortesía
- **Colaboración**: Trabajar juntos de manera constructiva
- **Comunicación clara**: Expresar ideas de forma clara y directa
- **Apertura**: Estar abierto a diferentes puntos de vista
- **Responsabilidad**: Asumir responsabilidad por las propias acciones

## 3. Comportamiento Inaceptable

- Uso de lenguaje ofensivo o discriminatorio
- Acoso de cualquier tipo
- Publicar información privada de otros sin consentimiento
- Conducta que pueda dañar la comunidad

## 4. Responsabilidades

### 4.1 Maintainers

Los maintainers del proyecto son responsables de:
- Aplicar este código de conducta de manera justa
- Revisar y aprobar cambios de manera oportuna
- Mantener un ambiente de trabajo saludable

### 4.2 Contributors

Los contributors son responsables de:
- Seguir las guidelines del proyecto
- Documentar el trabajo realizado
- Respetar las decisiones de diseño
- Mantener código de calidad

## 5. Alcance

Este código de conducta aplica a:
- Repositorios del proyecto
- Discusiones en issues y pull requests
- Comunicación oficial del proyecto

## 6. Aplicación

Las situaciones que violen este código de conducta pueden ser reportadas mediante:
- Abrir un issue descriptivo
- Contactar directamente a los maintainers

## 7. Atribución

Este código de conducta está adaptado de manera simplificada del [Contributor Covenant](https://www.contributor-covenant.org/).
